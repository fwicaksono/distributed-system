# PROJECT: Distributed Task Processing Platform

I want to build one end-to-end production-style learning project whose primary purpose is to learn backend architecture, distributed systems, AWS infrastructure, networking, observability, containerization, and CI/CD.

The business use case can remain intentionally simple. A normal web API / task management API is completely fine. Do NOT make the business logic unnecessarily complex.

The main learning objective is the ARCHITECTURE.

The final project should evolve from a simple single-server application into a distributed, scalable, observable, and deployable system running on AWS EC2.
